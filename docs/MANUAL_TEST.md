# 人工测试清单（真机）

> 代码与 `--selftest` 已覆盖逻辑；这里只列**必须真人在真机上确认**的部分。
> 每项：怎么做 → 应该看到什么 → 不对时日志里找什么。
> 日志：`~/Library/Application Support/GestureKit/gesturekit.log`（实时看：`tail -f` 这个文件）。
> 有问题记下「第几项 / 做了什么 / 实际发生了什么」，连同日志最后几十行一起反馈。

测试前：菜单栏 `◈` 存在且不是 `◈!`；BetterAndBetter 已退出（否则会双触发）。
终端里 `pgrep -lf GestureKit` 应只有**一行**（新版启动时会自动让旧实例退出）。

## A. 鼠标手势（5 分钟）

| # | 操作 | 预期 | 日志 |
|---|---|---|---|
| A1 | 网页里**按住右键**向右划一条线，松开 | 有浅蓝色轨迹；**不弹右键菜单**；网页前进（你的配置：→ 前进、← 后退） | `shape gesture score=` + `op=pageForward` |
| A1b | 在网页、访达、桌面各**单击右键**（不划） | 右键菜单照常弹出（松开时弹出，比平时晚一点点属正常） | 无 action 行 |
| A2 | 按住右键（不用划），再按一下键盘 **A** 键，然后松开右键 | 所有窗口最小化，**不弹右键菜单**（双键+V 同理为恢复全部） | `op=minimizeAll` |
| A3 | 单独按一下中键、侧键（第 4/5 键）；左键单击、拖选文字 | 和不开 GestureKit 时一样（Safari 本身不响应侧键） | 无 action 行 |
| A3b | 按住右键画四个折线：先上再左、先上再右、先下再左、先下再右（先在「普通鼠标 → 手势设置 → +」里给「上左/上右/下左/下右」各设一个动作） | 各自触发对应动作；两段长短不一也能认；画斜线仍是斜线手势 | `shape gesture score=` |
| A3c | 按住右键往上划再划回来（上下 ↑↓） | 当前页面刷新（⌘R） | `op=- key=15` |
| A3d | 「普通鼠标 → 手势设置」右上角应用程序下拉 →「添加应用程序…」选一个 App | 下拉切到该 App，提示「这里没有的手势沿用所有应用程序的规则」；用 + 给它加规则只在该 App 生效 | — |
| A3e | 应用程序下拉选 ego lite →「删除「ego lite」的专属规则…」→ 确认 | 下拉回到「所有应用程序」，列表里不再有 ego lite；同目录多一个 `rules.before-remove-app-*` 备份 | — |
| A4 | 「通用设置 → 鼠标手势」切回「左右双键」，按住左键再按右键划线 | 同样触发，不弹右键菜单；切回「右键」 | — |
| A5 | 「通用设置」改轨迹颜色/宽度后再画 | 颜色/粗细变化 | — |

### A+. 流畅度（重点，5 分钟）

1. 终端运行（新版会自动让正在运行的 GestureKit 退出，不会两个同时跑）：`GK_PERF=1 /Applications/GestureKit.app/Contents/MacOS/GestureKit`
2. 正常使用 1–2 分钟：快速画各种手势、长时间按住画大圈、在网页上滚轮、在右上角滚轮调音量（上下来回）。
3. 日志里每 10 秒一行 `perf tap: …`。**看 `>1ms=` 是否为 0、`p99` 是否在几十 µs 以内**。
4. 主观感受：画手势时光标是否跟手、轨迹是否连续不跳、松手到动作执行是否有可感知的停顿、
   右上角上下来回滚时音量是否跟着来回变（以前会「越调越小」）。
5. Ctrl+C 结束后 `open -a GestureKit` 恢复正常运行。

## B. 设置窗口（10 分钟）

| # | 操作 | 预期 |
|---|---|---|
| B1 | 普通鼠标 → 手势设置 → `+` | 面板默认选中一个**还没有规则**的手势，不应出现「将覆盖」红字 |
| B2 | 手势选「按住右键 + M」，动作「窗口布局 → 最大化」，备注「测试」，保存；然后画 M | 窗口最大化，提示显示「测试」 |
| B3 | 双击刚才那行 → 改动作 → 保存；选中后点 `−` | 修改生效；删除后不再触发 |
| B4 | `+` → 手势选「自定义绘图…」→ 在白框里画一个圈 → 动作随意 → 保存；按住双键画同样的圈 | 触发该动作 |
| B6 | 新动作：打开 App（Safari）/ 打开网址（apple.com）/ 输入文字（在文本编辑里测） | 各自正常；输入文字含中文和换行 |
| B7 | 「通用设置 → 语言」切 English，再切回「跟随系统」 | 设置窗口、菜单栏菜单立即切换；记下显示不全的文字 |
| B8 | 「通用设置」取消「菜单栏显示图标」，然后在访达 /Applications 里双击 GestureKit | 图标消失；双击后弹出设置窗口；再勾回 |
| B9 | 「通用设置」勾选「开机自启动」 | 「系统设置 → 通用 → 登录项」里出现 GestureKit |
| B10 | 普通鼠标 → 按键识别：依次按各个鼠标键；点「手动适配」走一遍 | 实时显示「第 N 键按下/松开」；适配结果列出各键编号 |
| B11 | 设备页底部「重置」→ 取消；再「重置」→ 确认 | 先弹确认框；确认后本页规则恢复出厂，其它页不变（同目录多一个 `rules.backup-*`） |
| B12 | 用旁白（⌘F5）读侧栏和 `+`/`−` | 读出页面名 / 「添加规则」「删除所选规则」 |
