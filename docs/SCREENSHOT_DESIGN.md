# 截图 + 截图衣架 设计（v0.4，已确认；三期均已实现）

> 2026-11-10 与用户讨论定稿前的方案。交互灵感来自开源项目 Tendedero（截图晾衣绳），
> **只参考交互，不看、不抄它的代码**（它不是常规开源许可证）。所有实现自己写。

## 1. 目标与范围

替代「微信截图」的日常用法：GestureKit 常驻后台，按快捷键就能截，不依赖微信是否开着。

| # | 功能 | 本期 |
|---|---|---|
| 1 | ⌃⌘A 截图：定格全屏 → 半黑遮罩 → 拖框 → 可调整 → 确认进剪贴板 | ✅ |
| 2 | 悬停高亮窗口，单击即选整个窗口 | ✅ |
| 3 | 选框旁显示尺寸（逻辑点 × 像素） | ✅ |
| 4 | 截图衣架：每次截图自动挂上，菜单栏中间悬停 / ⌃⌥T 展开 | ✅ |
| 5 | 钉图：从衣架或截图界面把图钉在屏幕上（置顶浮窗） | ✅ |
| 6 | 识别文字（Vision，本机离线） | ✅ |
| 7 | ⌘S 存到桌面 | ✅ |
| — | 标注 / 马赛克 / 长截图 / 录屏 / 收集系统截图或剪贴板 / 便签 / 分组 / 搜索 | ❌ 不做 |

## 2. 交互

### 2.1 截图界面

| 操作 | 效果 |
|---|---|
| ⌃⌘A（或「截图」动作，可绑手势/边角） | 先定格所有屏幕，再盖 45% 黑色遮罩 |
| 鼠标悬停在窗口上 | 高亮该窗口边框（来自定格时的窗口列表） |
| 单击（不拖） | 选中高亮的窗口；没有窗口则选整块屏幕 |
| 拖动 | 拉出选框，框内恢复亮度；旁边显示 `812 × 430` |
| 松手后 | 选框可调整：8 个控制点改大小，拖框内移动，方向键微移 1pt（⇧ 10pt） |
| 双击框内 / 工具条 ✓ | **复制到剪贴板 + 挂上衣架**（默认行为） |
| 回车 | **只复制，不挂** |
| ⌘S | 存 PNG 到桌面（同时复制 + 挂上） |
| P | 钉在屏幕上（同时复制 + 挂上） |
| T | 识别框内文字 → 文字进剪贴板，HUD 提示「已复制 N 字」 |
| Esc / 右键 | 取消；选框已存在时第一次 Esc 先清掉选框，再按一次退出 |

选框下方一条小工具条：`钉住  识别文字  存桌面  ✕  ✓`（与快捷键等价，鼠标党也能用）。

### 2.2 衣架

- 位置：菜单栏下方、屏幕正中，宽约 60% 屏宽；一根略微下垂的细线，卡片用**木夹子**夹着，每张随机歪 ±2°。
- 展开：鼠标在菜单栏正中（宽 160pt 的区域）停 0.3 秒，或 ⌃⌥T；离开 0.7 秒收起；点菜单栏其他地方立即收起。
- 新图挂上：从上方落下 + 阻尼摇摆约 0.8 秒（Core Animation，几乎不占 CPU）；衣架收起时挂图只在边缘闪一下提示。
- 容量：最近 **20** 张，新图在右；超出时最旧的掉落。**固定**的图用深灰夹子挂在最左边、不被挤掉、不计入 20。
- 持久化：`~/Library/Application Support/GestureKit/Clothesline/`（`index.json` + PNG），重启保留。只存在本机，不联网。

| 卡片操作 | 效果 |
|---|---|
| 单击 | 复制（卡片轻晃 + 「已复制」） |
| 双击 | 用「预览」打开 |
| 拖出 | 拖到 App = 发一份副本（衣架上保留）；拖到 Finder 文件夹 = 存一份 |
| 悬停 0.5 秒 | 在下方显示放大预览 + 尺寸 |
| 右键 | 钉在屏幕上 / 识别文字 / 存到桌面 / 固定(取消固定) / 删除 |

### 2.3 钉图

置顶无边框浮窗，带细阴影：拖动移动、滚轮缩放（25%–400%）、双击挂回衣架、Esc 或右上角 ✕ 关闭、⌘C 复制。可同时钉多张。

## 3. 技术方案

| 文件（新增） | 职责 | 可测的纯逻辑 |
|---|---|---|
| `Hotkey.swift` | Carbon `RegisterEventHotKey` 注册 ⌃⌘A / ⌃⌥T；被占用时记日志 + 菜单栏提示 | 快捷键编码 / 冲突处理 |
| `Capture.swift` | ScreenCaptureKit：`SCScreenshotManager` 定格每块屏幕；`SCShareableContent` 取窗口列表；按选框裁剪（Retina 原分辨率） | 点 → 像素换算、多屏坐标（左上/左下原点转换） |
| `CaptureSelection.swift` | 选框状态机：拖出 / 控制点 / 移动 / 微移 / 夹到屏幕内 / 最小尺寸 / 命中窗口 | 全部纯函数 |
| `CaptureOverlay.swift` | 每块屏幕一个 `.screenSaver` 层级无边框窗口，画定格图 + 遮罩 + 选框 + 尺寸 + 工具条 | — |
| `TextRecognition.swift` | Vision `VNRecognizeTextRequest`（中英文、精确模式），后台队列 | 渲染一张文字图做识别断言 |
| `Clothesline.swift` | 衣架数据：增删、20 张上限、固定、顺序、读写 `index.json` | 全部纯逻辑 |
| `ClotheslineWindow.swift` | 衣架界面、夹子与摇摆动画、拖出（`NSDraggingSource` 提供文件 URL）、悬停预览、右键菜单；菜单栏中间一条透明细窗口用 `NSTrackingArea` 检测悬停 | 展开/收起计时状态机 |
| `PinnedImage.swift` | 钉图浮窗 | 缩放夹取 |

接入现有代码：

- **动作**：`system` 下新增 `capture`（截图）与 `toggleClothesline`（显示衣架），登记 `ActionCatalog` + `Rules.swift` 注释 + 英文表。原有 `screenshotRegion` 等（调系统 `screencapture`）保留不动。
- **副作用**：`ActionEffects` 加 `startCapture()` / `toggleClothesline()`，测试用记录实现。
- **配置**：`captureEnabled`（缺省开）、`clotheslineEnabled`（缺省开）；快捷键先固定，后续需要再做可改。
- **设置窗口**：「通用设置」加一个「截图」小节：两个开关 + 快捷键说明 + 「打开衣架文件夹」+「清空衣架」。
- **权限**：新增「屏幕录制」。首次按 ⌃⌘A 时 `CGPreflightScreenCaptureAccess` 检查，没有就 `CGRequestScreenCaptureAccess` 并提示；权限向导里加一行状态。固定证书签名后授权不会因重编丢失。
- **线程 / 性能**：热键、悬停检测、截图界面都在主线程，**完全不经过事件 tap**，不改 tap 的监听掩码，对手势零影响。PNG 编码、写盘、OCR 在后台队列。截图界面打开时手势照常（遮罩窗口吞掉的是它自己的鼠标事件）。
- **隐私**：截图只进剪贴板和本机衣架文件夹；不联网、不上传、不读其他 App 的数据。

## 4. 分期与验收

每期：`./build.sh` 全绿且新增断言（`SelfTest+Capture.swift` / `SelfTest+Clothesline.swift`）、`--perf` 与 `--tap-isolation-test` 不退化、真机验证、更新 STATUS.md、单独提交。

1. **截图核心**（功能 1 2 3 7）：热键、定格、遮罩、选框、窗口高亮、尺寸、回车复制、⌘S、权限。
2. **衣架**（功能 4）：数据、界面、夹子动画、单击/双击/拖出/右键、自动挂图、持久化。
3. **钉图 + 识别文字**（功能 5 6）。
