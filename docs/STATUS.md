## 3. 已知技术债

1. **重签掉权限**：ad-hoc 签名按 cdhash 认身份，每次 `build.sh` 后要在系统设置里重新勾选辅助功能。
   → 已提供固定证书方案（见 P2-16），用户运行一次 `scripts/make-signing-cert.sh` 后解决。
2. **触控板坐标**：`NSEvent.swipe` 的 deltaX 方向与系统"自然滚动"相关，未做真机校准。
   MultitouchSupport 路线用传感器归一化坐标（左下原点），与自然滚动无关。
7. **多指手势与系统手势并存**：无法吞掉触控板帧，三/四指滑动会同时触发系统的调度中心/切换桌面；
   需要用户在「系统设置 → 触控板」里关掉冲突项（与原版一致）。
8. **平滑滚轮与 Mos / LinearMouse / Logi Options 冲突**：二选一。
10. **已修**：居中/最大化宽高以前都等于铺满；吸附/跨屏在多屏下混用了 AX 与 Cocoa 坐标；
    合成的快捷键会被自己的 tap 再次处理（规则「⌥← → 发送 ⌥←」会死循环）。现在所有合成事件带
    `eventSourceUserData = 0x474B5353`，引擎直接放行。
9. **多块外接屏的 DDC 对应关系**：IOAVService 与 CGDisplayID 的映射未做，接多块外接屏时会同时调所有 DDC 屏；
   Intel Mac 没有 IOAVService，外接屏只能走 DisplayServices（仅 Apple 显示器）。
3. **多屏热区**：用主屏高度做坐标基准，副屏未验证。
4. **`draining` 字段**：chord 结束后另一个键的 up 仍会放行（无实害，但不严谨）。
5. **开关类动作依赖外部命令**：WiFi（networksetup）、Fn（defaults）、Dock（killall）在沙盒/受限环境下可能失败。
6. **勿扰模式**：macOS 12+ 没有公开 API，尚未实现（需要 shortcuts 兜底）。

## 4. 怎么跑

```bash
cd GestureKit
./build.sh                                  # 编译 + 24 项自检 + 签名
./GestureKit.app/Contents/MacOS/GestureKit --selftest

cp -R GestureKit.app /Applications/ && open -a /Applications/GestureKit.app
```
