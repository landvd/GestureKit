# 16 多语言（中文 / English）

P2-15。代码：`Sources/L10n.swift`；自检：`Sources/SelfTest+I18n.swift`；检查脚本：`scripts/check-l10n.sh`。

## 设计

- **表驱动、单文件**：中文原文就是 key。`L("窗口最小化")` 英文下返回 `"Minimize Window"`，
  中文下原样返回。英文表缺这条时回退中文，并 `Log.write("l10n: missing English …")`（每个 key 一次）。
- **格式化**：`L("导入 %d 条规则", n)`，key 与译文用同样的 `String(format:)` 占位符。
- **拼接**：`L10n.join(a, b)` 中文直接相连、英文加空格（触控手势名「三指」+「上滑」）。
- 不用 `.lproj` / `Localizable.strings`：build.sh 只拷 Info.plist，保持 `swiftc Sources/*.swift`。

## 语言来源（优先级）

1. `L10n.override`：自检 / 调试强制。`SelfTest.run()` 开头设为 `"zh"`，所以现有比对中文文案的断言在任何系统语言下都通过。
2. `L10n.setting` = `Config.language`：`"system"`（缺省，存为 nil）/ `"zh"` / `"en"`；未知值按 system。
3. 跟随系统：`Locale.preferredLanguages` 第一项以 `zh` 开头 → 中文，否则英文（`L10n.systemLanguages` 可注入）。

结果有缓存，上面三项任一改动即失效。

## 切换即时生效

- 「通用设置 → 语言」Picker → `PrefModel.setLanguage` → `save` → `AppDelegate.applyLanguage`：
  更新 `L10n.setting`，语言变了就 `rebuildMenu()`。
- 设置窗口：`config` 是 `@Published`，保存后整个 `PreferencesView` 重算，`L(...)` 取新语言。
- HUD：每次显示时调用 `ActionCatalog.hudText`，自动是当前语言。
- 启动 / 「重新加载配置」时也从配置设置 `L10n.setting`。

## 约定

- 面向用户的文案一律 `L("中文")`；SwiftUI 里 `Text(L("…"))`（String，不走 LocalizedStringKey）。
- **不翻译**：用户的备注、规则存盘的 `label`（`ActionCatalog.choices` 的 `spec.label` 仍是中文原文）、日志、代码注释、语言名「中文」。
- `ActionCatalog` 的名称表值是中文 key，显示时经 `L` 翻译；`PrefPage.zhTitle` 是中文原文，`--prefs-page 边角触发` 用它匹配。
- 英文表在 `BEGIN-EN` / `END-EN` 之间，**一行一条** `"key": "value",`，key 里不写 `\"`（用「」）。

## 检查

- `scripts/check-l10n.sh`：源码里所有 `L("…")` 字面量 key 都必须在英文表里，缺失列出并非 0 退出（bash 3.2 / BSD grep/sed）。
- 动态 key（名称表、分类、手势名部件）由 `--selftest` 的 `i18n: *` 断言覆盖：英文下 ActionCatalog 每个选项名 / 分类、
  所有设备页的手势选项、各类手势 id 都有英文且不含中文；中文下与原文一致；回退、跟随系统、格式化、配置字段。
